# pizza_sales

# 🍕 Pizza Sales SQL Project

Welcome to the **Pizza Sales SQL Analysis** project! This project involves analyzing a fictional pizza sales database using SQL. The goal is to extract insights about orders, revenue, and customer preferences through structured queries.

---

## 📦 Dataset Assumptions

We are working with the following database schema:

### Tables:
- `orders(order_id, date)`
- `order_details(order_id, pizza_id, quantity)`
- `pizzas(pizza_id, pizza_type_id, size, price)`
- `pizza_types(pizza_type_id, name, category)`

---

## 🧠 Project Questions & Objectives

### ✅ Basic Level

| # | Question | Objective |
|---|----------|-----------|
| 1 | Retrieve the total number of orders placed | Understand total volume of orders |
| 2 | Calculate total revenue from pizza sales | Know how much revenue is generated |
| 3 | Identify the highest-priced pizza | Find the most expensive pizza |
| 4 | Identify the most common pizza size ordered | See which size is most popular |
| 5 | Top 5 most ordered pizza types with quantities | Discover the most frequently ordered pizzas |

---

### 🔁 Intermediate Level

| # | Question | Objective |
|---|----------|-----------|
| 1 | Total quantity of each pizza category ordered | Compare categories by quantity |
| 2 | Distribution of orders by hour | Analyze ordering trends by time |
| 3 | Category-wise distribution of pizza types | Understand order patterns by category |
| 4 | Average pizzas ordered per day | Identify daily trends and averages |
| 5 | Top 3 pizza types by revenue | Find the most profitable pizza types |

---

### 🚀 Advanced Level

| # | Question | Objective |
|---|----------|-----------|
| 1 | % contribution of each pizza type to revenue | Measure each pizza’s share of total sales |
| 2 | Cumulative revenue over time | Track how revenue grows over time |
| 3 | Top 3 pizza types by revenue per category | Find bestsellers within each category |

## 🎯 Expected Outcomes

### 📘 Basic
- Learn how to use basic SQL queries
- Practice aggregate functions like `COUNT`, `SUM`, `MAX`, and `GROUP BY`
- Filter and sort data effectively

### 📗 Intermediate
- Gain experience in joining multiple tables
- Group and aggregate data in meaningful ways
- Work with dates, times, and averages

### 📙 Advanced
- Learn advanced SQL operations:
  - Subqueries
  - Window functions (`RANK()`, `OVER`)
  - Percentage calculations
  - Cumulative revenue tracking
- Gain skills used in real-world data analysis

## ⚙️ How to Use

1. Clone this repository
2. Import the pizza sales dataset into your SQL environment (MySQL, PostgreSQL, etc.)
3. Open and run the SQL queries in any SQL editor
4. Explore insights and modify queries for deeper analysis
